I built this mostly as a learning project for haskell. 

The implementation is heavily inspired by the papers [A Play on Regular Expressions](https://sebfisch.github.io/haskell-regexp/regexp-play.pdf) and [Monadic Parser Combinators](https://people.cs.nott.ac.uk/pszgmh/monparsing.pdf), with an additional goal of compiling the project to WebAssembly so it can run directly in the browser.
